# copi 実装計画

承認済み：2026-09-30。macOS向けnpm CLI、AIなしの対話ウィザード、ファイル単位のテンプレート群。
公開名：@papillon6814/copi。実行名：copi。MIT。公開権限は未確認。公開・実際のホーム検索・個人設定の取り込みは禁止。
保存形式：~/.copi/catalog.jsonに定義・元パス・適用先・群の所属を記録し、~/.copi/items/に実体コピーを保存。同じ定義を複数群で共有。
実装順：合成データのテスト → 収集・保存 → 複製 → 対話UI → パッケージ検証。feature worktreeでworkerが段階実装し、親が検証する。

- package.json：ESM、darwin、Node.js 22.19以上、copi実行名。Clack・diffを明示依存にし、公開ファイルをコード・README・LICENSEに限定。
- package-lock.json：採用した依存を固定。
- tsconfig.json：strictなTypeScriptでソース・テストをビルド。
- .gitignore：依存・ビルド・worktree・生成アーカイブを除外。
- LICENSE：MIT。個人が取り込んだ定義にはこのライセンスを適用しない。
- README.md：導入、操作、秘密情報・依存・既存copiコマンドとの衝突、Pi設定の適用制限を記載。UIとREADMEは初版英語。
- src/types.ts：定義の種類、保存項目、群、警告、適用計画の型。
- src/discovery.ts：許可したホーム内を検索。Pi設定・共有スキル場所・設定から参照される資産を候補化。除外・権限エラー・検索範囲外リンクを報告。
- src/catalog.ts：ユーザー専用権限の~/.copiへコピーと所属を保存。原本は変更しない。再取り込みは選択・確認後だけ反映。
- src/inspect.ts：auth/.env/履歴/キャッシュを除外。秘密情報候補、絶対パス・不足依存・ユーザー専用設定を警告。内容・コマンドは実行しない。
- src/groups.ts：群の作成・名前と所属の変更・複数所属を管理。本文は分割しない。
- src/apply.ts：AGENTS等はルート、skills/agents/settings/MCP等は対応するプロジェクト配置へコピー。グローバル専用定義は保存のみ。
- src/wizard.ts：検索・複数選択・プレビュー・群割当・保存確認。秘密の疑いがあるファイルは保存と適用時に個別確認し、表示は既定でマスク。
- src/cli.ts：setup、groups、list、apply <群> [宛先]、apply --dry-run、help。非TTYで対話が必要な変更は停止。
- test/discovery.test.ts：標準/独自プロファイル・プロジェクト・参照資産・除外・権限失敗・範囲外リンク。
- test/catalog.test.ts：原本不変、原本削除後も利用可能、複数所属、再取り込み、キャンセル時の無変更。
- test/inspect.test.ts：秘密の疑いと環境変数参照の区別、マスク、除外、警告。検出の限界も明記。
- test/apply.test.ts：配置、群内衝突、既存との同一/差分、維持/中止/バックアップ付き置換、バイナリ資産、権限、宛先逸脱の拒否。自動マージはしない。
- test/cli.test.ts：CLI引数・非TTY・dry-run・公開アーカイブと実行名。合成HOMEのみを使用。
- test/wizard.test.ts：群割当、秘密の個別許可、差分選択、取消。合成データの端末スモークテストも実施。

検証条件：strictビルド、Node標準テスト、合成HOMEでの操作確認、npm pack --dry-run。実機UI確認ができない場合は未確認と報告。
